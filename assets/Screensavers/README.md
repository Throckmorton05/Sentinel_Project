# Sentinel wallpapers

The two designs are static desktop and lock-screen wallpapers. KDE displays each
as one named wallpaper package and chooses among its four bundled resolutions.

| KDE name | Source folder | Filename prefix |
| --- | --- | --- |
| Sentinel Gradient | `Sentinel_SS_Gradients/` | `sentinel-dark-gradient` |
| Sentinel Navy Waves | `Sentinel_SS_Wave/` | `sentinel-navy-waves` |

Each folder contains a PNG and editable SVG for 3840×2160 (16:9), 3840×2400
(16:10), 5120×2160 (ultrawide), and 5120×1440 (super-ultrawide). The PNGs are the
installed display assets; SVGs are source artwork. Keep their paired filenames.

The ISO and `sentinel-platform` install them under
`/usr/share/wallpapers/SentinelGradient` and `/usr/share/wallpapers/SentinelWaves`.
Gradient is the first-install background. Updates replace installed artwork and
preserve the user's selected desktop and lock-screen background.
